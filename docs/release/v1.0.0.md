## Lệnh chạy (macOS/Linux, tối đa 3 lệnh)

```bash
git clone https://github.com/Youngboy1609/K5-L3B-LAB-Day12-AI-SDLC-Strawberry.git
cd K5-L3B-LAB-Day12-AI-SDLC-Strawberry
python3 -m chonoi.live --mode day --days 5
```

Yêu cầu: Python 3 (thư viện chuẩn) và trình duyệt. Mở địa chỉ in ra (mặc định
http://127.0.0.1:8000/). Phím và lệnh test/headless/benchmark/soak: xem
[README](../../README.md).

## Kết quả kiểm đã ghi nhận

### Báo cáo từ nhánh tài liệu trước khi tích hợp cuối

Hạnh ghi nhận kết quả trên macOS Darwin arm64, CPython 3.15.0 ở nhánh tài liệu
trước tích hợp cuối: suite đầy đủ
đạt, headless Gather 600 tick mã 0 với 62 dòng JSONL, Live Gather trả HTTP 200
và thử điều khiển, Live Day trả HTTP 200. Đây là kết quả được ghi trong lượt
đóng gói trước đó, chưa chạy lại trên SHA phát hành cuối.

### Bằng chứng ứng viên tích hợp

[Ma trận nghiệm thu Phase 4](../verification/phase-4.md) ghi kiểm tra trên
Windows, Python 3.11.9: 217/217 test v1.3, 197/197 hồi quy v1.1, JSONL ba mode
giống byte, benchmark/soak đạt và ZIP ứng viên qua kiểm tra giải nén. Ma trận
còn ghi việc phát hành tag và GitHub Release là bước chưa hoàn tất.

### Kiểm tra độc lập trong lượt review này

- Nền tảng: Windows, CPython 3.11.9. Ubuntu-24.04 có trong WSL nhưng WSL không
  khởi động được vì không tìm thấy tệp `ext4.vhdx`; không có macOS runtime.
- Tạo và giải nén source archive sạch từ PR #21. `python -m unittest discover
  -s tests` đạt 202 test. `python -m chonoi.headless --mode gather --seed 42
  --ticks 600 --out out.jsonl` trả mã 0 và tạo 62 dòng JSONL.
- Khởi tạo `LiveServer` trực tiếp từ archive và GET `/`: HTTP 200, 62.152 byte.
  Đây là smoke HTTP, chưa kiểm soát nhân vật bằng phím trong trình duyệt.
- Các kết quả trên là kiểm tra Windows từ archive source, không phải kiểm tra
  macOS/Linux hoặc ZIP phát hành cuối.

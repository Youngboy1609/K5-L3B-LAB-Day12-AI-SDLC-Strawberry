## Lệnh chạy (macOS/Linux, tối đa 3 lệnh)

```bash
git clone https://github.com/Youngboy1609/K5-L3B-LAB-Day12-AI-SDLC-Strawberry.git
cd K5-L3B-LAB-Day12-AI-SDLC-Strawberry
python3 -m chonoi.live --mode day --days 5
```

Yêu cầu: Python 3 (thư viện chuẩn) và trình duyệt. Mở địa chỉ in ra (mặc định
http://127.0.0.1:8000/). Phím và lệnh test/headless/benchmark/soak: xem
[README](../../README.md).
